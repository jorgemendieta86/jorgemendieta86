# Jorge Mendieta

**Magíster en Educación e Ingeniero de Sistemas**

Desarrollo web orientado a la educación y a la metodología de la investigación. Diseño sitios institucionales y herramientas que docentes y estudiantes pueden usar en el aula, sin depender de un servidor.

## Desarrollo web

Trabajo interfaces y aplicaciones que corren en el navegador:

- HTML, CSS y JavaScript para sitios y herramientas pedagógicas
- Astro y TypeScript cuando el sitio necesita componentes y una estructura mantenible
- Generación de documentos (programaciones, unidades y sesiones) y guardado local del avance
- Publicación en Vercel y Netlify

El criterio es práctico: que la herramienta respete el flujo docente y se pueda abrir, usar y compartir con poca fricción.

## Uso de IA

Uso la IA como apoyo de desarrollo, no como reemplazo del criterio pedagógico ni del diseño curricular.

- Prototipar interfaces y flujos
- Revisar y refactorizar HTML, CSS, JavaScript, TypeScript y Astro
- Ordenar documentación y textos de apoyo
- Acelerar tareas repetitivas de maquetación y validación

Herramientas habituales: GitHub Copilot, ChatGPT, Claude, Cursor y Gemini. El contenido educativo, la estructura de cada producto y la revisión final los defino yo.
